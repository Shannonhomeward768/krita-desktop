## 📌 What krita-desktop Does

krita-desktop is described as a local Windows and macOS helper for Krita data paths, config and export caches, and export folders. In everyday use, that means it helps with the housekeeping that sits around your artwork:

- Finding common Krita data folders on your computer.
- Showing where Krita configuration files are stored.
- Helping you review or manage export cache locations.
- Opening export folders so you can find finished images more easily.
- Keeping helper actions local to your computer.
- Reducing the need to hunt through hidden folders by hand.

The utility is especially useful if you export artwork often, change Krita settings, or want a clearer view of where Krita keeps its working files. It is intended for normal desktop use on Windows, with the repository description also noting macOS helper use. The download and run steps in this README focus on Windows because that is the main end-user path.

## 🧹 Export Cache and Folder Help

Export caches and export folders can become confusing because they are often outside the main Krita project folder. krita-desktop gives you a clearer way to reach them.

An export cache is a temporary or supporting storage area used during export work. You normally do not need to open it by hand. If you want to review disk usage or clean up after a large export session, the helper can point you to the right place. Treat cache cleanup carefully: close Krita first, review what is present, and remove only files you recognize as temporary export data.

An export folder is where finished images are saved. If you frequently export PNG, JPEG, or other image files, the helper can open that folder quickly. This is useful when you want to rename files, move finished artwork into a project folder, or attach an image to a message.

If you are not sure whether a folder is a cache or a final export location, open it and look at the file names before changing anything. Keep backups of important artwork. Do not delete a folder just because the helper can open it.

If you use a portable-style Krita setup or store your work in a custom location, review the paths shown by the helper before making changes. The helper can make folders easier to reach, but you should still confirm that each path matches your own setup.

If you are unsure about a configuration file, do not edit it. Open the folder, make a backup if needed, and leave the file unchanged until you know what it controls.
